# Repository visual

The original README artwork uses evergreen, cream and coral: two physical microphones connected by
one continuous film strip. It makes conversation-to-clips tangible without inventing a customer,
interface screen or result metric.

Final asset: `docs/assets/project-hero.png`. Generation mode: built-in image generator.

Prompt: premium editorial still life, wide 2:1. Two matte dark evergreen broadcast microphones face
one another on a warm ivory desk. A continuous translucent film strip between them forms three
portrait frames. Restrained coral edges/detail, cream background, paper texture, soft studio shadows,
tactile materials and generous breathing room. No people, faces, logos, text, tiny UI, glowing tech
effects, watermarks or code wallpaper.

The app uses bundled licensed fonts. Screenshots and frame sheets are actual captures, not generated
UI. This cover does not establish podcast quality, caption accuracy or production speed.
